# 光谱波长校准台

校准员提交标称波长与实测波长。独立领取进程按允差写出合格或超差。页面轮询直到结论出现。

连续超差触发自动缓领：领取进程发现最近已结案连续超差条数达到阈值时，在缓领秒数内暂停领取普通待处理（急测待处理仍可领取），开始与解除各写一条闸门流水。顶栏「缓领闸」页分阈值设置、缓领秒数、当前是否缓领、起止流水四块总览；顶栏角落的「缓领中」只是提示不算页。校准员可改阈值与秒数（只约束此后新结案串，不追溯改写旧流水），巡检员只能查看。


## 验收

1. calibrator 登录后，种子「氦灯-587」合格、「汞灯-546」超差。
2. 再提交超差样条，先待处理再出超差。
3. inspector 不能提交，也不能改缓领阈值与秒数。
4. 缓领闸页把连续条数定为 2，接连投入两笔必超差普通样条：闸页显示正在缓领，起止流水出现「开始缓领」。
5. 缓领未结束时再投普通待处理迟迟不被领走，同时投一笔急测仍能被领走。
6. 缓领秒数耗尽后流水出现「解除缓领」，普通队恢复领取。
