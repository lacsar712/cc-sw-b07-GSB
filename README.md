# 光谱波长校准台

校准员提交标称波长与实测波长。独立领取进程按允差写出合格或超差。页面轮询直到结论出现。

连续超差会自动落下缓领闸：领取进程发现最近已结案串的连续超差条数达到阈值时，在缓领秒数内暂停领取普通待处理（急测待处理照常），开始与解除各写一条流水。

## 缓领闸

- 顶栏「缓领闸」页分四块：阈值设置、缓领秒数、当前是否缓领、起止流水；缓领中另有角落提示（不算页面）。
- 校准员设定连续超差阈值与缓领秒数；改动只约束此后新结案串，不追溯改写旧流水。
- 领取进程在结案为超差时检查最近已结案串：连续超差条数达到阈值即开始缓领，写「开始缓领」流水。
- 缓领期间普通待处理暂停领取，急测待处理（提交时勾选「急测」）仍可领取。
- 缓领秒数耗尽后写「解除缓领」流水，普通队恢复领取。

## 启动

```bash
cd projects/16-spectrum-wavelength-desk

```

## 验收

1. calibrator 登录后，种子「氦灯-587」合格、「汞灯-546」超差。
2. 再提交超差样条，先待处理再出超差。
3. inspector 不能提交，也不能改阈值与秒数。
4. 缓领闸页把连续条数定为 2，接连投入两笔必超差普通样条：闸页显示正在缓领，起止流水出现「开始缓领」。
5. 缓领未结束时再投普通待处理迟迟不被领走；同时投一笔急测仍能被领走。
6. 缓领秒数耗尽后流水出现「解除缓领」，普通队恢复领取。
